## Project Setup Instructions

This project is scaffolded using Vite with React 18 and TypeScript. To get started, follow the steps below:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akshay-goAI/Interactive-Dashboard-UI.git
   cd Interactive-Dashboard-UI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to see your application in action.

### Configuration

In the `tsconfig.json`, make sure to keep the following setting:
```json
{
  "compilerOptions": {
    "strict": true
  }
}
```

### Vite Configuration

The Vite configuration is located in `vite.config.ts`. Ensure it is set up to use the latest React features and optimizations.
