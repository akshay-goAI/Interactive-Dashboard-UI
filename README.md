# Project Overview

This project aims to enhance the interactive dashboard's accessibility features, ensuring compliance with WCAG standards and improving user experience for all users.

## Features
- Enhanced accessibility for users with disabilities
- Improved navigation and usability of dashboard elements

## Getting Started

To run the project, ensure you have the necessary dependencies installed and follow the setup instructions.

## Accessibility Improvements

As part of the ongoing efforts to harden accessibility features, we have implemented several enhancements to the dashboard. These include:
- Keyboard navigation support
- ARIA roles and properties for better screen reader compatibility
- Color contrast adjustments to meet WCAG standards

For more details, refer to the [Jira Story: Harden accessibility features](https://your-jira-instance/browse/STORY-001).
